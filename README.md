# Retail Operations Performance Analysis

## Project Overview
This portfolio project analyses operational performance across a fictional 14-store clothing retail area over a four-week reporting period.

The objective is to turn raw retail operations data into actionable insights that support management decision-making, store prioritisation, and performance monitoring.

## Business Questions
- Which stores are meeting sales targets?
- Where are returns and customer complaints highest?
- Which stores experience the most stockout incidents?
- How does sales productivity vary by labour hours?
- Which operational areas should management prioritise?

## Tools
- Microsoft Excel
- Power Query
- PivotTables
- Excel formulas and charts
- GitHub

## Key Areas of Analysis
- Sales performance and target achievement
- Returns value and return rate
- Customer complaints
- Stockout incidents
- Labour productivity
- Store and regional comparisons

## Deliverable
The Excel workbook contains the operational analysis, summary reporting, charts, and executive summary.

## Data Note
The dataset is fictional and was created for portfolio demonstration purposes.

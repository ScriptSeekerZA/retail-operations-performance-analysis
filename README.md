# Retail Operations Performance Analysis

## Project Overview
This portfolio project analyses operational performance across a fictional 14-store clothing retail area over a four-week reporting period.

The project demonstrates how retail operations data can be cleaned, analysed, and transformed into actionable insights to support management decision-making, store prioritisation, and performance monitoring.

## Business Objectives
The analysis focuses on:
- Sales performance against targets
- Returns value and return rate
- Customer complaints
- Stockout incidents
- Labour productivity
- Store and regional performance comparisons

## Project Workflow
1. Reviewed the business context and reporting requirements.
2. Inspected and profiled the raw dataset.
3. Cleaned and prepared the data in Excel.
4. Validated the cleaned data for quality and consistency.
5. Analysed operational KPIs using Excel formulas and PivotTables.
6. Built two dashboards to communicate store and operational performance.
7. Developed an executive summary with key findings and management recommendations.

## Tools Used
- Microsoft Excel
- Power Query
- Excel formulas
- PivotTables
- Charts and dashboards
- GitHub

## Key Deliverables
- Cleaned and analysis-ready dataset
- KPI and performance analysis
- Two operational dashboards
- Executive summary and management recommendations

## Key Findings
The analysis identified differences between stores in returns, customer complaints, stockout incidents, and sales productivity.

The dashboards highlight operational areas requiring further investigation and provide a basis for targeted store reviews and performance improvement actions.

## Recommendations
- Investigate return patterns to identify preventable product, process, or service issues.
- Conduct root-cause reviews at stores with high customer complaints.
- Review replenishment and stock allocation at stores with frequent stockouts.
- Compare labour scheduling and sales patterns to identify productivity improvements.
- Monitor operational KPIs regularly and assign action owners.

## Data Note
The dataset is fictional and was created for portfolio demonstration purposes.
